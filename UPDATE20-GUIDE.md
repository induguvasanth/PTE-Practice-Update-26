# Update 20 — Student filter for section and topic progress

Added **Student** dropdown directly beside Section, Topic, and Completion filters on the Teacher Dashboard. Select All students or one registered student. Topic cards, counts, averages, last finished question, and student breakdown reflect that selection. The existing Students overview selection continues to work independently; the topic student filter narrows the overview selection further when used.

## Install
1. Replace the Apps Script HTML file named `Teacher` with `Google-Apps-Script/Teacher.html` from this ZIP.
2. Save, then Deploy > Manage deployments > Edit > New version > Deploy.
3. Refresh the Teacher Dashboard.

No changes to Code.gs, Google Sheets, or GitHub Pages are required.
